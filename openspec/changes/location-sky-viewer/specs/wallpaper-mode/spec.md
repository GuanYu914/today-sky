## ADDED Requirements

### Requirement: 啟用桌布模式
系統必須提供桌布模式，以極簡、無干擾的視圖顯示天空，適合作為背景使用。

#### Scenario: 啟動桌布模式
- **WHEN** 使用者點擊「啟用桌布模式」按鈕
- **THEN** 系統隱藏 UI 控制項並顯示全螢幕天空視圖

#### Scenario: 離開桌布模式
- **WHEN** 使用者在桌布模式中按下 ESC 鍵或移動滑鼠
- **THEN** 系統顯示 UI 控制項和離開選項

### Requirement: 自動更新天空
系統必須在桌布模式下定期自動更新天空狀況。

#### Scenario: 定期更新
- **WHEN** 桌布模式啟動時
- **THEN** 系統每隔可設定的間隔更新天空資料（預設：1 小時）

#### Scenario: 平滑過渡
- **WHEN** 桌布模式中天空資料更新時
- **THEN** 系統在天空狀態之間平滑過渡，沒有突兀變化

### Requirement: 可設定更新頻率
系統必須允許使用者設定桌布模式中天空更新的頻率。

#### Scenario: 設定更新頻率
- **WHEN** 使用者存取桌布設定
- **THEN** 系統允許選擇更新間隔（每小時、每 4 小時、每天）

### Requirement: 持久化桌布偏好設定
系統必須在瀏覽器工作階段之間記住使用者的桌布模式設定。

#### Scenario: 儲存桌布偏好設定
- **WHEN** 使用者設定桌布設定
- **THEN** 系統將偏好設定儲存至 local storage
- **AND** 下次造訪時還原偏好設定

### Requirement: 最小化資源使用
系統必須在桌布模式期間最佳化資源使用，以防止過度的 API 呼叫或電池消耗。

#### Scenario: 有效率的資料擷取
- **WHEN** 桌布模式啟動時
- **THEN** 系統快取天氣資料，僅在設定的間隔擷取更新

#### Scenario: 分頁不活動時暫停
- **WHEN** 瀏覽器分頁不活動或最小化
- **THEN** 系統暫停自動更新以節省資源
