## ADDED Requirements

### Requirement: 取得即時天氣狀況
系統必須從天氣資料提供者取得所選地點的即時天氣狀況。

#### Scenario: 成功取得天氣資料
- **WHEN** 使用者選擇有效的地點
- **THEN** 系統取得包含雲量、降水和溫度的即時天氣狀況

#### Scenario: Weather API 無法使用
- **WHEN** weather API 無法連線或回傳錯誤
- **THEN** 系統顯示友善的錯誤訊息並呈現預設天空狀態

### Requirement: 計算時段光線
系統必須根據地點座標和目前時間計算準確的太陽和月亮位置。

#### Scenario: 白天天空渲染
- **WHEN** 目前時間介於該地點的日出和日落之間
- **THEN** 系統顯示適合太陽位置的白天天空色彩

#### Scenario: 夜晚天空渲染
- **WHEN** 目前時間介於日落和日出之間
- **THEN** 系統顯示帶有星星和月亮（如果可見）的夜晚天空

#### Scenario: 黎明/黃昏過渡
- **WHEN** 目前時間在日出或日落的 1 小時內
- **THEN** 系統顯示暮光色彩（golden hour、blue hour）

### Requirement: 渲染天空外觀
系統必須根據天氣狀況和時間渲染天空的視覺呈現。

#### Scenario: 晴朗天空渲染
- **WHEN** 天氣顯示晴朗狀況
- **THEN** 系統顯示平滑的天空漸層且沒有雲

#### Scenario: 多雲天空渲染
- **WHEN** 天氣顯示多雲狀況
- **THEN** 系統根據雲量百分比疊加雲的紋理或圖案

#### Scenario: 雨天天空渲染
- **WHEN** 天氣顯示降水
- **THEN** 系統顯示較暗的天空色調和雨的視覺指標

### Requirement: 顯示地點和時間脈絡
系統必須在天空視覺化旁顯示目前地點名稱和當地時間。

#### Scenario: 顯示地點脈絡
- **WHEN** 顯示某地點的天空
- **THEN** 系統顯示地點名稱和目前當地時間

### Requirement: 響應式天空顯示
系統必須在不同螢幕尺寸上響應式地渲染天空顯示。

#### Scenario: 桌面檢視
- **WHEN** 從桌面瀏覽器存取
- **THEN** 天空以適當的尺寸填滿視口

#### Scenario: 行動裝置檢視
- **WHEN** 從行動裝置瀏覽器存取
- **THEN** 天空適應行動裝置螢幕尺寸而不失真
